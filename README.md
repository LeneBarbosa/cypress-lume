
# 🧪 Cypress Lume

Projeto de **automação de testes E2E** desenvolvido com **Cypress**, com o objetivo de praticar conceitos de Quality Assurance (QA), automação de testes e validação de funcionalidades de uma aplicação web.

## 📌 Sobre o projeto

Este projeto foi desenvolvido durante meus estudos em **QA e automação de testes**, utilizando o Cypress para criar e executar cenários de testes automatizados.

O objetivo é aplicar na prática conceitos como:

- Testes funcionais
- Testes End-to-End (E2E)
- Automação de testes
- Seletores CSS
- Validações e asserções
- Interação com elementos da página
- Testes de cenários positivos e negativos
- Organização de testes
- Boas práticas de automação

## 🛠️ Tecnologias utilizadas

- JavaScript
- Cypress
- Node.js
- Git
- GitHub
- Visual Studio Code
